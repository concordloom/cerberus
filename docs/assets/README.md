# Brand assets

## `hero-gopnik.png`

The README hero is an edited version of an image generated with ChatGPT by the
repository owner. The original composition established the character, cat,
black-and-orange palette, and street-comic style. The public edit corrects the
speech bubble, replaces the absolute “bug free” claim with “no fake green”, and
uses a wider crop.

The 1717×916 PNG stays detailed enough for GitHub's responsive rendering. Its
meaning is repeated in accessible README text; the embedded words are tone, not
the only product explanation.

## `logo.svg`

The primary Cat Gate mark. The cat's ears and open sides form a release gate;
the face challenges the claim, and the asymmetric orange check is what remains
after the challenge. It uses explicit dark, warm-white, and orange colours so
it renders consistently through an external `<img>`.

## `mark-16.svg`

The small-size mark keeps only the gate outline and glare. The proof check is
removed because it becomes noise at favicon scale.

## `wordmark.svg`

The horizontal lockup uses a custom single-stroke lowercase wordmark rather
than a system font. The final orange slash carries the same adversarial accent
as the Cat Gate mark.
